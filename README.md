# Colorir

Livro de colorir para adultos (PWA), pensado para iPad com Apple Pencil.

- Catálogo gerado por código (mandalas, vitrais, quilts, espirógrafos, mosaicos) e importação de imagens/PDF.
- Balde, pincel com pressão e "dentro das linhas", borracha, conta-gotas, desfazer.
- Gravação automática no dispositivo (IndexedDB), exportação PNG e cópia de segurança.
- Acesso por chave no link: `?k=<chave>` (só o resumo SHA-256 está no código).

Ficheiros estáticos, sem build. `vendor/` contém pdf.js (Apache-2.0).
